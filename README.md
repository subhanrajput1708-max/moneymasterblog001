# Money Master Blog

> Practical Personal Finance Guides, Financial Calculators & Everyday Online Tools.

**Money Master Blog** (hosted at [moneymasterblog.site](https://www.moneymasterblog.site/)) is an educational personal finance publication and online utilities hub. It provides reader-first financial guides, step-by-step loan calculations, and a collection of 25 fast, browser-based calculators and digital tools designed for everyday decision-making.

---

## 🌟 Key Features

### 🛠️ 25 Functional Online Tools & Calculators
All 25 tools run directly in the visitor's web browser using native Web APIs (Canvas, Cryptography API, standard math algorithms). No entered figures, passwords, or personal datasets are ever uploaded to a remote server.

#### 1. Financial & Everyday Calculators (8 Tools)
1. **Loan Payment Calculator** (`/tools/loan-payment-calculator.html`): Compute monthly installments, total interest, and full repayment with fixed-rate amortization formulas.
2. **Percentage Calculator** (`/tools/percentage-calculator.html`): Calculate percentage increases, percentage decreases, discounts, and proportional changes.
3. **GST / Tax Calculator** (`/tools/gst-tax-calculator.html`): Add or extract GST, VAT, and sales tax with custom rates and pre/post-tax breakdowns.
4. **Tip & Bill Splitter** (`/tools/tip-calculator.html`): Calculate dining tips, split checks evenly across groups, and round totals to whole dollars.
5. **Age Calculator** (`/tools/age-calculator.html`): Chronological age in years, months, days, with upcoming birthday countdown.
6. **Date Difference Calculator** (`/tools/date-difference-calculator.html`): Calculate calendar duration, total weeks, and business days between dates.
7. **Timestamp Converter** (`/tools/timestamp-converter.html`): Convert Unix epoch timestamps to UTC/Local dates and dates to epoch seconds/milliseconds.
8. **Random Number Generator** (`/tools/random-number-generator.html`): Generate unbiased random integers, lottery picks, or dice rolls.

#### 2. Text Tools (7 Tools)
9. **Text Cleaner** (`/tools/text-cleaner.html`): Standardize messy text, strip irregular whitespace, remove blank lines, and sanitize formatting artifacts.
10. **Word Counter** (`/tools/word-counter.html`): Live word, character, sentence, paragraph counts, and estimated reading time.
11. **Character Counter** (`/tools/character-counter.html`): Track character limits with and without spaces for social posts and SEO.
12. **Case Converter** (`/tools/case-converter.html`): Convert text between UPPERCASE, lowercase, Title Case, camelCase, snake_case, and kebab-case.
13. **Lorem Ipsum Generator** (`/tools/lorem-ipsum.html`): Produce customizable placeholder text by paragraph, sentence, or word count.
14. **Text Reverser** (`/tools/text-reverser.html`): Invert characters, reverse word order, flip lines, or mirror text.
15. **Text-to-Slug Generator** (`/tools/slug-generator.html`): Generate clean, SEO-friendly URL slugs with optional stop-word filters.

#### 3. Developer & Web Tools (6 Tools)
16. **Base64 Converter** (`/tools/base64-converter.html`): Encode text to Base64 or decode Base64 strings safely.
17. **URL Encoder/Decoder** (`/tools/url-converter.html`): Percent-encode URLs or decode complex query strings.
18. **JSON Formatter & Validator** (`/tools/json-formatter.html`): Beautify, validate syntax, sort keys, and minify JSON.
19. **UUID Generator** (`/tools/uuid-generator.html`): Generate cryptographically secure RFC 4122 Version 4 UUIDs in bulk.
20. **QR Code Generator** (`/tools/qr-code-generator.html`): Create custom, high-resolution downloadable QR code PNGs.
21. **Random Password Generator** (`/tools/password-generator.html`): Generate cryptographically strong random credentials using `crypto.getRandomValues()`.

#### 4. Image Tools (4 Tools)
22. **Color Palette Generator** (`/tools/color-palette.html`): Generate harmonic palettes, inspect HEX/RGB values, lock colors, and export CSS variables.
23. **Image Compressor** (`/tools/image-compressor.html`): Compress JPG, PNG, and WebP images locally with custom quality controls.
24. **Image Resizer** (`/tools/image-resizer.html`): Scale image dimensions with aspect ratio lock and social media presets.
25. **Image Cropper** (`/tools/image-cropper.html`): Crop photos to preset aspect ratios (1:1, 4:3, 16:9, 9:16) or freeform.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or newer recommended)
- npm

### Installation
```bash
# Clone or download repository
git clone https://github.com/your-username/moneymasterblog.git
cd moneymasterblog

# Install dependencies
npm install

# Start local dev server (port 3000)
npm run dev
```

The application will be accessible at `http://localhost:3000/`.

### Building for Production & Sitemap Generation
```bash
npm run build
```
This runs the Vite production bundler and executes `scripts/generate-sitemap-and-pages.ts` to:
1. Compile the React SPA bundle in `dist/assets/`.
2. Generate static, pre-rendered HTML for all **8 core pages**, **25 tools**, and **20 articles**.
3. Generate the canonical `sitemap.xml` with all 53 URLs.
4. Synchronize `robots.txt`, `ads.txt`, and `CNAME`.
